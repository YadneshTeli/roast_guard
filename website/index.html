Modular Architecture

Built Different from Other Wellbeing Apps

Traditional screen-time apps demand active effort and sell your data. RoastGuard takes over the cognitive load entirely.

Native Floating Overlay Interception

Runs as a background foreground service using Android's native SYSTEM_ALERT_WINDOW. When your time limit is crossed, it renders directly over the offending app with a compulsory reality check.

Engineering

End-to-End Pipeline Architecture

From native usage polling to model inference, token scrubbing, and immediate UI overlay presentation.

1

Android UsageStats Poller

Monitors package foreground events via native Kotlin service every 15 seconds without draining battery.

2

Dual-Engine Routing

Routes requests to Google Gemma 4 open weights as primary, falling back to ultra-low-latency Groq Llama 3 when offline.

3

Stream & Regex Scrubbing

Strips <think> blocks in memory before strings are written to SharedPreferences or dispatched to the UI.

4

System Alert Overlay

Floats over third-party apps, locking touch focus until the user either closes the app or acknowledges the shame timer.
